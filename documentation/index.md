# Périscolaire — Documentation administrateur

Cette documentation accompagne le secrétariat de mairie dans l'utilisation quotidienne du plugin Périscolaire.

Le plugin centralise les inscriptions, le planning, la cantine et la facturation afin que les familles et la mairie travaillent à partir des mêmes informations.

## Configuration

Préparez l'année scolaire, le calendrier, les tarifs et les messages avant l'ouverture du service. Consultez [Année scolaire](configuration/annee-scolaire.md).

## Gestion au quotidien

Suivez les demandes, les absences, les menus et les documents transmis par les familles. Consultez le [Tableau de bord](gestion-quotidienne/tableau-de-bord.md).

## Facturation

Générez les factures mensuelles et préparez les exports nécessaires au suivi des règlements. Consultez [Factures PDF](facturation/factures-pdf.md).

## Cycle annuel

Organisez la réinscription des familles et le passage de classe des enfants. Consultez la [Campagne de réinscription](cycle-annuel/reinscription.md).

## Données personnelles

Traitez les demandes d'accès ou d'effacement des données personnelles dans WordPress. Consultez [Données personnelles (RGPD)](rgpd.md).

## Installation & maintenance

Installez le plugin, sécurisez son fonctionnement et assurez sa maintenance technique. Consultez les [Prérequis](installation/prerequis.md).

Commencez par le [Démarrage rapide](demarrage-rapide.md).
