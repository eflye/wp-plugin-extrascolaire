# Notes de changement du fournisseur

## Objectif

Reportez dans le menu de cantine les remplacements de dernière minute annoncés par le fournisseur de repas (« la tomme noire est remplacée par du camembert ») : vous déposez sa note, la page vous propose le menu du jour corrigé, vous le relisez et le modifiez si nécessaire, puis vous l'enregistrez.

## Avant de commencer

Connectez-vous avec un rôle autorisé à gérer la cantine. Enregistrez sur votre poste la note Word (`.docx`) reçue du fournisseur, **sans la renommer** : la date qui figure dans le nom du fichier (par exemple `… 09-11-26.docx` pour le 9 novembre 2026) désigne le jour de repas concerné. Le menu de ce jour doit déjà être enregistré dans **Menus de la semaine**.

## Étapes

1. Ouvrez **Périscolaire › Menus**, onglet **Notes du fournisseur**. Sous **Déposer une note de changement**, choisissez le fichier reçu puis cliquez sur **Déposer la note**. Rien n'est modifié à cette étape.
2. Relisez le **Texte de la note**, repris tel que le fournisseur l'a écrit.
3. Vérifiez le **Jour de repas concerné**. S'il est faux, ou si le nom du fichier ne portait pas de date, choisissez le bon jour dans **Autre jour** puis cliquez sur **Changer le jour**. Un avertissement s'affiche quand la note parle d'un jour de la semaine différent de la date retenue.
4. Sous **Menu du jour à corriger**, la page liste ce que la note annonce et affiche deux colonnes : le **Menu actuel** du jour, et le **Menu corrigé**, déjà rempli avec les remplacements reconnus. Le menu corrigé se présente en cinq champs, un par type de plat (**Entrée**, **Plat**, **Accompagnement**, **Fromage / Laitage**, **Dessert**) : relisez-les et modifiez-les librement, un plat par ligne dans chaque champ ; terminez une ligne par une étoile `*` pour un produit bio.

    !!! note
        La lecture automatique n'est qu'une aide. Seules les phrases du type « … est remplacé par … » sont reconnues, et un produit peut ne pas être retrouvé dans le menu : la page le signale, et le menu corrigé reprend alors le menu actuel. Dans tous les cas, c'est le texte que vous laissez dans **Menu corrigé** qui fait foi.

5. Cliquez sur **Enregistrer le menu corrigé**. Seul le menu du jour concerné est remplacé ; les autres jours ne changent pas.
6. Si le menu avait déjà été envoyé aux familles, il est corrigé dans le backoffice et dans leur espace, **sans nouvel e-mail**. Pour les prévenir, cliquez sur le lien **Voir le menu de cette semaine**, puis sur **Renvoyer** dans **Menus enregistrés**.
7. Si la note ne vous concerne pas, cliquez sur **Classer la note sans modifier le menu**.

## Résultat attendu

Le menu du jour concerné affiche les produits de remplacement, la note apparaît **Appliquée au menu** dans **Notes reçues** avec les lignes modifiées, et aucun e-mail n'est parti sans que vous l'ayez décidé.
